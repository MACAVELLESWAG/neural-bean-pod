# Neural Bean Pod - Quantum Amp

Aesthetic JUCE + Neural Amp Modeler guitar plugin. Red metallic pod GUI with glowing yellow accents.

Built for stunning visuals and real-time NAM model loading.

## Features
- Exact replica of the bean_red.png hardware-style interface
- Filmstrip knob controls from knob_filmstrip.png
- Live waveform 'TUBE LINE CLONE' display
- Full Neural Amp Modeler core integration
- Ready for VST3 / AU / Standalone

## Build Instructions
1. Clone this repo
2. Open in Projucer or use CMake
3. Add bean_red.png and knob_filmstrip.png to Resources
4. Build with JUCE 8+
